# 📁 Capstone Project – Multi-Process System Monitor


This capstone project focuses on building a Multi-Process System Monitor, a lightweight and efficient tool designed to observe and analyze system performance in real time. The project leverages multiprocessing techniques to separate system monitoring tasks into parallel processes, improving efficiency and responsiveness.

# 🔍 Key Features:  
Real-time monitoring of CPU, memory, disk usage, and active processes.

Modular architecture using multi-processing for scalable performance.

Clean and interactive UI/CLI output to present data in a user-friendly format.

Efficient resource tracking with minimal system overhead.

Logs and reports for post-analysis and debugging.

🛠️ Purpose:
This project demonstrates a practical understanding of process management, system-level programming, and performance analysis. It's a valuable tool for developers, system administrators, or researchers looking to gain insights into system behavior or diagnose performance bottlenecks.
